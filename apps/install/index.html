How to install

  1. Tap the download button The file starts downloading straight away — about 85 MB, so use Wi‑Fi if you can.
  2. Open the downloaded file Check the notification bar, or find it in your Downloads folder.
  3. Allow installation from this source Manara PM is distributed directly rather than through the Play Store, so Android will ask for permission once. Turn it on and go back.
  4. Sign in Enter your mobile number and the code you receive. The app opens straight to the sign-in screen.
