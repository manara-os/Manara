How to install

  1. Open the download page on your phone Tap the button above, or scan the QR code with your camera app.
  2. Tap “Install” The APK file starts downloading. It is about 60 MB.
  3. Open the downloaded file Check the notification bar, or find it in your Downloads folder.
  4. Allow installation from this source Android blocks apps from outside the Play Store by default. When it asks, turn the permission on and go back — this is expected for a test build.
  5. Sign in Use the test account below. The app opens straight to the sign-in screen.

The first screen may take up to a minute. The test server sleeps when nobody is using it and needs about 50 seconds to wake up. Pull down to refresh once it does — every screen after that loads normally.

Reinstalling? Remove the old Manara PM first, then install the new file. Android will not replace it otherwise.
